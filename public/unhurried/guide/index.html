01 · Install

Two ways in

The directory is the easy way. Updates then arrive like any other theme's.

  1. From WordPressAppearance → Themes → Add New. Search for Unhurried, click Install, then Activate.
  2. Or from the zipDownload unhurried.zip from the latest GitHub release and upload it under Appearance → Themes → Add New → Upload Theme.
  3. Keep the folder nameThe theme folder must be called unhurried. GitHub's green Code button zip unpacks as unhurried-main, which breaks updates and Unhurried Pro. Use the release zip.

Works with WordPress 6.6 or newer, PHP 7.4 or newer, block themes only. Tested on WordPress 7.1.

02 · Homepage

Two minutes to a front page

  1. Pages → Add NewIn the page settings on the right, pick the Ground artboard template.
  2. Pick the Homepage patternWordPress offers page patterns when the page is empty. Choose Homepage. Later, it is under + → Patterns → Pages.
  3. Publish, then make it the front pageSettings → Reading → Your homepage displays → A static page.
  4. Build the rest the same wayAbout, Services and Contact each have a page pattern. Use the Canvas template for those.

Every section is a pattern you can add, move or remove. Pattern buttons link to your Contact and Services pages once those pages exist. There is a getting-started screen at Appearance → About Unhurried.

04 · Styles

One theme, five looks

Styles → Browse styles in the Site Editor. Each look changes only colours, or in Folio's case only the heading face, so your content never moves.

  1. NocturneInk paper, Bone type, a warm glow accent.
  2. LinenWarm paper with a sage accent.
  3. MistCool grey paper, slate ink, an ochre accent. New in 1.1.
  4. FolioHeadings in Fraunces italic, with the accent word flipped to upright sans. New in 1.1.

Small things that are always on: write an italic word inside a heading and it becomes the Fraunces accent. Choose the Reveal on scroll block style for a gentle entrance. Add the class unhurried-mono to a block to show its images in greyscale, and the Keep colour image style to opt one image back out. Groups take the Panel, Card, Ink, Ground and Glass section styles.
